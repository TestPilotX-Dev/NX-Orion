## ⚡ How It Works

NX Orion automatically monitors for new Nintendo Switch firmware releases. When a new version is detected, it is downloaded, verified, and published — no manual intervention required.

Each release includes:
- Firmware ZIP with all NCA files (FAT32 + exFAT)
- SHA-256 hash for integrity verification
- SystemVersion NCA identifiers

## 🔒 Integrity

All firmware files are verified against official CNMT records before packaging. The SHA-256 hash of every archive is published in the release notes.
